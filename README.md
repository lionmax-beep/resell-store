# ReSellX – Reselling Website

A modern responsive reselling storefront made with **HTML + CSS + JavaScript**.

## Files
- `index.html` – main website
- `style.css` – complete responsive design
- `script.js` – products, filters and cart
- `README.md` – setup guide

## GitHub Pages
1. Create a new GitHub repository.
2. Upload all files in this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save. GitHub will give you the live website URL.

## Customize
Open `script.js` and edit the `products` array to add your own products and prices.

For real orders, replace the demo `checkout()` function with WhatsApp, Google Forms, or a backend/database.
